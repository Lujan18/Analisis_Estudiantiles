# Analisis_Estudiantiles 
## Analisis del rendimiento academico en estudiantes
### Este proyecto lleva a cabo un profundo anlisis sobre los factores que pueden ser determinantes para el rendimiento academico. Dicho analisis se lleva a cabo utilizando Python, Google Colab con realizaciones de visualiaciones con graficos en Power BI.
# Fuenten de los datos utilizados 
## Creacion independiente con objetivo de practica con Google Colab. 
### En esta fuente de datos se conserva y maneja imformacion sobre un determinado grupo estudiantil, donde se observan claves fundamentales para el entendimiento de las caracteristicas del rendimiento academico de los gupos estudiantiles.
# Listado de herramientas utilzadas 
* Python
* Pandas y Numpy
* Matplotlib, Seaborn , Plotly
* Power BI
